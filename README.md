# کتابسرای پردیس

فرانت فارسی و RTL با React، TypeScript، Vite و Tailwind CSS.

## اجرا

```sh
npm install
npm run dev
```

آدرس پیش‌فرض: http://127.0.0.1:5173

```sh
npm run build
npm run preview
npm run test:ui
```

تست مرورگر با Microsoft Edge نصب‌شده اجرا می‌شود. تصاویر بررسی در `test-results/landing-{width}.png` ذخیره می‌شوند.

## وضعیت تحویل

هر ۱۱ بخش صفحه پیاده شده است: نوار اعلان، هدر، هیرو، محصولات، مزایا، روند سفارش، هشدار موجودی، نظرات، سوالات متداول، تماس و فوتر. لینک‌های منو و استعلام محصولات به بخش‌های متناظر صفحه می‌روند. آکاردئون با صفحه‌کلید کار می‌کند و در هر لحظه فقط یک پاسخ باز می‌ماند.

## تنظیم محتوا

- `src/data/site.ts`: شماره ثابت و همراه، لینک کامل بله و ایتا، ناوبری، اطلاعات جلدها، قیمت‌ها (تومان)، تخفیف‌ها، مزایا، مراحل سفارش، نظرات و پاسخ سوالات. مقدار `null` تماس‌ها را غیرفعال نگه می‌دارد؛ برای فعال‌سازی شماره واقعی با کد کشور و URL کامل پیام‌رسان‌ها را وارد کنید. قیمت و درصد تخفیف مستقل‌اند و باید هنگام تغییر با هم به‌روزرسانی شوند.
- تصاویر واقعی را در `public/images` قرار دهید و مسیرهایی مانند `/images/top-notch.webp` را در ویژگی `cover` کتاب‌ها بنویسید. جای‌نگهدارها خودکار جایگزین می‌شوند.
- `src/components/Hero.tsx` و `TopBar.tsx`: متن کمپین. تخفیف و موجودی متن نمایشی‌اند و به سرویس زنده متصل نیستند.
- `src/styles.css`: ورودی Tailwind، رنگ‌های مشترک و فونت محلی بسته Vazirmatn؛ در زمان اجرا نیازی به Google Fonts نیست.

آیکون برند و پیام‌رسان‌ها فعلاً بازنمایی ساده‌اند و در صورت دریافت فایل رسمی قابل جایگزینی هستند. هیچ API، پرداخت یا ثبت سفارش سمت سرور وجود ندارد.

قیمت‌ها، نشانگر موجودی، شماره‌های نمونه و نظرات صرفاً داده نمایشی‌اند و در صفحه مشخص شده‌اند. پیش از انتشار، با اطلاعات تأییدشده جایگزین شوند. آواتار نظرات از حروف نام ساخته می‌شود و عکس شخص واقعی نیست.

بررسی مرورگر شامل پنج عرض ۳۶۰، ۳۹۰، ۷۶۸، ۱۰۲۴ و ۱۴۴۰ پیکسل، منوی موبایل، آکاردئون، لینک‌های داخلی، عدم اسکرول افقی و خطاهای کنسول است.
